# Archive

This directory keeps legacy or uncertain files out of the active runtime tree without deleting them.

- `frontend-vite/`: previous Vite frontend, archived after `frontend_next/` became the active app.
- `notebooks/`: exported or duplicate notebook-derived files that are not directly referenced.
- `project-state/`: local planning/status notes.
- `agents/`: local cleanup-agent prompt notes.

Archived files are not part of the current runtime path. Review before deleting permanently.
